# One-Line Laugh-Off

Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on [make.fun](https://make.fun).

`main.py` writes exactly one funny line to `/output/entry.txt` — a single joke that lands on a cold read, with no setup notes and no explanation:

> I asked AI to write my wedding vows. It proposed to my fiancée instead.

## Run

```sh
python3 main.py
```

The program validates its own output against the gate (exactly one line, 1–200 UTF-8 characters) before writing it.
